Trusted Certificate & Installation

🛡️

Splitwise P2P Local CA

Verified Local Authority

Modern mobile browsers (Chrome on Android, Safari on iOS) require a trusted HTTPS certificate to enable 1-tap app installation and offline background caching.

📥 Download Root CA Certificate

How to Install on Your Device:

1
Android (Phones & Tablets)
1. Tap Download Root CA Certificate above.
2. Open phone Settings → Security & Privacy → More security settings → Install from device storage → CA certificate (or search "CA Certificate" in Settings).
3. Tap Install anyway and select splitwise-root-ca.crt.
4. Return to Chrome and tap Menu (3 dots) → Install app / Add to Home screen.
2
iPhone & iPad (iOS)
1. Tap Download Root CA Certificate in Safari and tap Allow.
2. Open Settings → Profile Downloaded → Install.
3. Go to Settings → General → About → Certificate Trust Settings and turn ON Full Trust for Splitwise Root CA.
4. In Safari, tap the Share button → Add to Home Screen.
3
Windows, Mac & Linux
Double-click the downloaded splitwise-root-ca.crt and choose Install Certificate → Trusted Root Certification Authorities.
